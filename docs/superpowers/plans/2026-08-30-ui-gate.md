### Step 3: Implement the pure functions

### Step 4: Implement the Playwright assertions

- `assertNoDocumentOverflow`: compare document and body scroll width/height with the viewport, allowing at most one CSS pixel for rounding; all intentional overflow must belong to a named internal pane.
- `assertScrollOwner`: verify a designated region is actually scrollable when its content exceeds its box and that the document width does not change after setting `scrollTop`/`scrollLeft`.
- `assertMinimumContrast`: read computed foreground/background colors, walk through transparent ancestors, calculate the ratio, and include the selector plus observed colors in failures.
- `assertVisibleFocus`: focus the locator and require either a non-zero outline or box shadow plus an accessible name.
- `assertSafeUiGateSurface`: reject executable descendants and inline event attributes in user-controlled content, matching the existing safe-DOM audit style.
- `assertNoSensitiveCanaries`: inspect public DOM text/attributes plus bounded captured API responses and browser/server logs for auth tokens, raw prompts, private filesystem paths, and seeded secret canaries. Never print a matched secret in the failure message.
- `captureUiGate`: create the output directory and save a full-page PNG using the normalized path.

Add focused unit coverage for color parsing and path validation where it remains pure. Avoid duplicating Playwright behavior in mocks.
